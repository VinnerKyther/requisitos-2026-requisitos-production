# Requisitos e Regras (GAC - Gestão de Ativos do CCT)

## 1. Requisitos Funcionais (RF)
Os Requisitos Funcionais definem as ações e comportamentos que a plataforma digital GAC deve obrigatoriamente executar para resolver os problemas de controle manual e garantir a rastreabilidade.

**Retirada e Identificação**
*   **RF01:** O sistema deve permitir que o professor consulte a disponibilidade e realize a retirada de um equipamento utilizando seu celular, através da leitura de QR Code ou aproximação NFC.
*   **RF02:** O sistema deve exibir um termo de responsabilidade e exigir o aceite digital do professor para liberar a retirada do equipamento.

**Devolução e Conferência**
*   **RF03:** O sistema deve permitir que o atendente registre a devolução dos equipamentos, alterando o status do item no inventário.
*   **RF04:** O sistema deve apresentar um checklist técnico rigoroso (conferência de acessórios e estado físico) que deve ser obrigatoriamente preenchido pelo atendente durante a devolução.
*   **RF05:** O sistema deve permitir que o atendente registre avarias ou defeitos no equipamento, caso sejam identificados durante a devolução.

**Gestão e Inventário**
*   **RF06:** O sistema deve possuir uma interface administrativa centralizada (painel/dashboard) para a coordenação acompanhar o inventário e o status dos equipamentos em tempo real.
*   **RF07:** O sistema deve permitir que o administrador realize o cadastro detalhado de novos equipamentos (projetores, chaves e acessórios).
*   **RF08:** O sistema deve possuir uma funcionalidade para registrar e agendar manutenções preventivas e corretivas dos ativos.

**Notificações e Relatórios**
*   **RF09:** O sistema deve gerar automaticamente um histórico (auditoria) de uso de cada equipamento, registrando quem retirou, horários e responsável.
*   **RF10:** O sistema deve enviar lembretes e alertas automáticos para os usuários e administradores sobre prazos de devolução e eventos de atraso.
*   **RF11:** O sistema deve permitir a geração e exportação de relatórios analíticos e estratégicos baseados no uso do sistema.
