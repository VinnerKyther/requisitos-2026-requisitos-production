### Glossário de Termos - Sistema GAC

#### Histórico de Versões
| Data | Versão | Descrição | Autor |
| ------ | ------ | ------ | ------ |
| 07/05/2026 | 1.0 | Criação do glossário com os termos iniciais do projeto GAC | [Requisitos Production] |

#### 1. Objetivo
Este documento visa padronizar o vocabulário utilizado no projeto **GAC (Gestão de Ativos do CCT)**. Ele serve como referência para desenvolvedores, analistas, alunos, professores e a coordenação, evitando ambiguidades no entendimento dos requisitos e regras de negócio.

#### 2. Termos e Siglas

| Termo / Sigla | Definição |
| :--- | :--- |
| **Ativo** | Qualquer item físico de valor pertencente ao patrimônio do centro acadêmico que pode ser emprestado (ex: projetores, chaves de laboratório, cabos HDMI, controles remotos). |
| **CCT** | **Centro de Ciências Tecnológicas**. Unidade acadêmica da Unifor onde o sistema será implantado e validado. |
| **Checklist Técnico** | Formulário de conferência rigorosa aplicado pelo atendente no momento da devolução de um equipamento, visando verificar a integridade física e a presença de todos os acessórios originais. |
| **Elicitação** | Processo de coleta e descoberta de requisitos junto aos usuários e partes interessadas (ex: por meio de entrevistas e questionários). |
| **GAC** | **Gestão de Ativos do CCT**. É o nome oficial do sistema/plataforma digital proposta neste projeto de extensão. |
| **Inventário** | A relação completa, centralizada e digital de todos os equipamentos e chaves disponíveis para locação no CCT. |
| **NFC** | *Near Field Communication* (Comunicação por Campo de Proximidade). Tecnologia de aproximação que será utilizada nas etiquetas (tags) coladas nos projetores para identificação rápida via celular. |
| **QR Code** | *Quick Response Code* (Código de Resposta Rápida). Código de barras bidimensional impresso nos equipamentos que pode ser escaneado pela câmera do celular para identificação no sistema. |
| **SRS** | *Software Requirements Specification* (Especificação de Requisitos de Software). Documento final que detalhará todos os requisitos funcionais e não-funcionais do sistema. |
| **Termo de Responsabilidade** | Documento digital que exige o "aceite" (assinatura eletrônica) do professor no momento da retirada via mobile, transferindo a ele a responsabilidade pela guarda e conservação do item até a devolução. |
| **UML** | *Unified Modeling Language* (Linguagem de Modelagem Unificada). Padrão visual (diagramas) utilizado para modelar os fluxos, classes e casos de uso do sistema GAC. |
