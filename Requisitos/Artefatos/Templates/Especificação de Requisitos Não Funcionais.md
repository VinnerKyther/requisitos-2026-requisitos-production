# Especificação de Requisitos Não Funcionais

| ID | Descrição do Requisito | Categoria |
| :--- | :--- | :--- |
| **RNF01** | A interface da aplicação mobile (focada em "uso rápido") deve ser responsiva e adaptável aos sistemas operacionais Android e iOS. | Compatibilidade |
| **RNF02** | O tempo de resposta na leitura do identificador físico (NFC ou QR Code) e o carregamento do termo na tela não deve ultrapassar 3 segundos. | Desempenho |
| **RNF03** | O sistema deve garantir a proteção dos dados dos usuários envolvidos, com armazenamento seguro das assinaturas digitais, em conformidade com a LGPD. | Segurança |
| **RNF04** | A interface web/desktop de gestão deve estar disponível 24/7 para permitir acesso da Coordenação a qualquer momento. | Disponibilidade |
