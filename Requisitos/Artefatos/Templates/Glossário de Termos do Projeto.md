# Glossário de Termos do Projeto

| Termo | Definição |
| :--- | :--- |
| **GAC** | Sigla para "Gestão de Ativos do CCT", que é o nome da plataforma digital do projeto [2]. |
| **CCT** | Centro de Ciências Tecnológicas (bloco da instituição) [2]. |
| **Ativo** | Equipamentos de valor controlados pelo sistema, como projetores, chaves e acessórios [3, 4]. |
| **NFC / QR Code** | Tecnologias de identificação por aproximação ou leitura óptica fixadas nos equipamentos para facilitar a retirada via aplicativo mobile [3, 5]. |
| **Termo de Responsabilidade** | Documento digital assinado no aplicativo pelo professor no momento da retirada do ativo [5]. |
| **Checklist Técnico** | Formulário de conferência rigorosa dos acessórios e do estado físico do ativo, preenchido pelo atendente na devolução [5]. |
